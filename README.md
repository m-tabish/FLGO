 
# Experimental Protocol for Comparing FLGO vs Baseline on Facial Emotion Recognition

### Deep learning models for Facial Expression Recognition (FER) often rely too heavily on dominant regions like the mouth, making them weak when faces are partly covered. We introduce  Facial  Landmark-Guided  Occlusion  (FLGO), uses facial  landmarks  to  smartly  hide key  areas  so  the  learns  from the  whole  face.  Tested  on  AffectNet  with  ResNet-18,  FLGO  keeps similar  accuracy  on  clean  images  and  improves  results  on  occluded faces by 8.51%. Notably, recognition of  Happy and Surprise shows strong gains under occlusion.
